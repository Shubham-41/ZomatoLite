### **Project Description: Restaurant Filtering and Listing Web App**

This project is a dynamic web application designed to showcase a collection of restaurants with powerful filtering and sorting capabilities. Inspired by platforms like Zomato, the app provides users with an intuitive interface to explore and discover restaurants based on their preferences.

**Key Features:**

- **Interactive Filters:** Users can filter restaurants by rating, price range, discounts, and more. A dedicated popup allows for advanced sorting options.
- **"Open Now" Feature:** Dynamically displays restaurants that are currently open, considering both same-day and next-day closing times.
- **Offer Highlights:** Restaurants can be sorted by the highest available discounts, making it easier for users to find great deals.
- **Dynamic Card Generation:** Each restaurant is displayed as an attractive card, featuring its name, rating, food type, price, location, and distance from the user.
- **Clean and Responsive Design:** The application is styled for a modern, user-friendly experience with responsive layouts for all devices.
